## Why We Chose Blue → Violet → Purple

### Educational Context
1. **Trust**: Blue is associated with learning and knowledge
2. **Creativity**: Purple sparks imagination and creativity

### Market Positioning

2. **Professional**: Maintains educational credibility
3. **Unique**: Stands out from traditional education apps

## Usage Guidelines

### Do's ✅
- Use blue for primary actions (Practice Mode)
- Use purple for secondary actions (Olympic Mode)
- Use violet for badges and achievements
- Combine all three in gradients
- Use on dark backgrounds for maximum impact

### Don'ts ❌
- Don't use pure pink as primary color (too playful)
- Don't mix with warm colors (orange, red)
- Don't use low opacity on light backgrounds
- Don't use for error messages (use red)
- Don't overuse gradients (keep it strategic)

## Gradient Combinations

### 1. Primary Hero Gradient
```css
background: linear-gradient(135deg,
  hsl(217 91% 60%) 0%,    /* Blue */
  hsl(250 95% 65%) 50%,   /* Violet */
  hsl(280 91% 60%) 100%   /* Purple */
);
```
**Use**: Hero sections, main backgrounds, primary CTAs

### 2. Secondary Gradient
```css
background: linear-gradient(135deg,
  hsl(280 91% 60%) 0%,    /* Purple */
  hsl(320 100% 60%) 100%  /* Pink */
);
```
**Use**: Secondary buttons, special features, premium content

### 3. Success Gradient
```css
background: linear-gradient(135deg,
  hsl(142 71% 55%) 0%,    /* Green */
  hsl(189 94% 53%) 100%   /* Cyan */
);
```
**Use**: Success messages, completion screens, achievements
