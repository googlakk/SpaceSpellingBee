# Новые функции тренировки слов 🚀

## Что добавлено

### 1. 📋 Интерактивный список слов

**Как открыть:** Нажмите кнопку "All Words (N)" во время тренировки

**Функции:**
- 🔊 **Аудио кнопка** - нажмите на иконку динамика рядом со словом, чтобы прослушать его
- 🎯 **Переход к слову** - кликните на само слово, чтобы начать тренировку с этого слова
- 📊 **Визуальная индикация:**
  - ✅ Зеленая рамка = уже пройденные слова
  - 🚀 Синяя рамка с подсветкой = текущее слово
  - Серая рамка = еще не пройденные слова

### 2. 🏆 Модальное окно завершения

**Когда появляется:** Автоматически после прохождения всех слов миссии

**Что показывает:**
- 🎉 Поздравление
- 📊 Статистику:
  - Количество слов
  - Заработанные монеты
  - Лучшая серия (streak)
  - Использованные подсказки

**Кнопки:**
- **"Restart Mission"** 🚀 - начать эту же миссию сначала
- **"Return to Levels"** 🏠 - вернуться к выбору уровней

### 3. 💾 Автосохранение прогресса (улучшено)

**Что сохраняется:**
- Текущее слово (на каком остановились)
- Монеты
- Streak (серия)
- Количество использованных подсказок

**Как работает:**
- ✅ Автоматически сохраняется после каждого действия
- ✅ При возврате на уровень показывает: "Progress restored! Continuing from word X"
- ✅ Для каждого уровня свой прогресс
- ✅ Автоматически очищается при завершении миссии

**Сброс прогресса:**
- Кнопка с иконкой ракеты 🚀 в Quick Actions (справа от "All Words")
- Или через кнопку "Restart Mission" в окне завершения

## Примеры использования

### Сценарий 1: Прослушивание слов
1. Нажмите "All Words"
2. Кликните на иконку 🔊 рядом с любым словом
3. Слово озвучится, но тренировка продолжится с текущего слова

### Сценарий 2: Переход к конкретному слову
1. Нажмите "All Words"
2. Кликните на само слово (например, слово #7)
3. Тренировка продолжится с этого слова
4. Прогресс-бар обновится

### Сценарий 3: Завершение миссии
1. Правильно напишите последнее слово
2. Появится 🎉 конфетти
3. Откроется окно с поздравлением и статистикой
4. Выберите: начать заново или вернуться к уровням

### Сценарий 4: Прерывание и продолжение
1. Пройдите 5 из 10 слов
2. Закройте браузер
3. Откройте снова и выберите тот же уровень
4. Появится уведомление: "Progress restored! Continuing from word 6"
5. Продолжите с того места, где остановились

## Технические детали

**Файлы:**
- `src/pages/practice/ui/PracticePage.tsx` - основная логика
- `src/features/track-progress/model/progressStorage.ts` - утилиты сохранения

**Хранилище:**
- localStorage с ключами `practice_progress_${sublevelId}`
- Автоматическая очистка при завершении

**Совместимость:**
- Работает во всех современных браузерах
- Не требует подключения к интернету (после загрузки)
- Данные хранятся локально

## Известные ограничения

- Прогресс сохраняется только в текущем браузере
- При очистке данных браузера прогресс будет потерян
- Прогресс не синхронизируется между устройствами
- Аудио воспроизводится через встроенный HTML5 Audio API
