# 📱 PWA Setup Guide - Intellect Pro School Spelling Bee

## ✅ Что было сделано

Приложение теперь настроено как **Progressive Web App (PWA)**, что позволяет ученикам устанавливать его на свои телефоны как нативное приложение!

### Созданные файлы:

1. **`public/manifest.json`** - Манифест PWA с метаданными приложения
2. **`public/sw.js`** - Service Worker для оффлайн поддержки и кэширования
3. **`src/registerSW.ts`** - Утилиты для регистрации Service Worker
4. **`src/components/PWAInstallPrompt.tsx`** - Автоматическая подсказка установки (через 5 сек)
5. **`src/components/InstallButton.tsx`** - ⭐ **НОВОЕ!** Кнопка "Установить приложение"
6. **`generate-icons.html`** - Генератор иконок PWA
7. **Обновлен `index.html`** - Добавлены PWA мета-теги и манифест
8. **Обновлен `HomePage`** - Добавлена кнопка установки на главной странице
9. **Обновлен `Header`** - Добавлена кнопка установки в шапку (доступна на всех страницах)

## 🎨 Генерация иконок (ВАЖНО!)

### Шаг 1: Сгенерировать иконки

1. Откройте файл `generate-icons.html` в браузере
2. Иконки сгенерируются автоматически
3. Нажмите кнопку "⬇ Download" под каждой иконкой
4. Сохраните все иконки в папку `public/` с именами:
   - `icon-72x72.png`
   - `icon-96x96.png`
   - `icon-128x128.png`
   - `icon-144x144.png`
   - `icon-152x152.png`
   - `icon-192x192.png`
   - `icon-384x384.png`
   - `icon-512x512.png`

**Альтернатива:** Вы можете создать свои собственные иконки в Figma/Photoshop и экспортировать их в указанных размерах.

## 🚀 Как установить PWA на телефон

### ⭐ НОВОЕ! Кнопка "Установить приложение"

Теперь в приложении есть **удобная кнопка "Установить приложение"**:

1. **На главной странице** - большая кнопка под кнопками "Launch Training" и "Practice Mode"
2. **В шапке сайта** - компактная кнопка в верхнем меню (видна на всех страницах)

**При нажатии на кнопку:**
- **На Android** - откроется нативный диалог установки
- **На iOS** - появится пошаговая инструкция установки

### Альтернативный способ (через браузер):

#### На Android (Chrome):

1. Откройте приложение в Chrome браузере
2. Нажмите на меню (три точки) в правом верхнем углу
3. Выберите **"Добавить на главный экран"** или **"Установить приложение"**
4. Подтвердите установку
5. Приложение появится на главном экране как обычное приложение!

#### На iOS (Safari):

1. Откройте приложение в Safari браузере
2. Нажмите кнопку **"Поделиться"** (📤) внизу экрана
3. Прокрутите вниз и выберите **"На экран «Домой»"**
4. Нажмите **"Добавить"**
5. Приложение появится на главном экране!

## 🛠️ Разработка и тестирование

### Локальное тестирование PWA:

1. Запустите приложение: `npm run dev`
2. Откройте в Chrome: `http://localhost:8080`
3. Откройте DevTools (F12)
4. Перейдите на вкладку **Application** → **Service Workers**
5. Проверьте, что Service Worker зарегистрирован
6. Перейдите на вкладку **Manifest** и проверьте манифест

### Тестирование на реальном устройстве:

1. Задеплойте приложение на HTTPS хостинг (требование PWA)
2. Откройте на мобильном устройстве
3. Установите приложение
4. Проверьте работу оффлайн (включите режим полета)

### Chrome Lighthouse Audit:

1. Откройте DevTools → Lighthouse
2. Выберите категории: PWA, Performance
3. Нажмите "Analyze page load"
4. Получите рекомендации по улучшению

## 📝 Требования для продакшена

### ⚠️ ВАЖНО: PWA требует HTTPS!

PWA работает **только на HTTPS** (или localhost для разработки).

При деплое убедитесь что:
- ✅ Сайт работает на HTTPS
- ✅ Все иконки загружены в `public/`
- ✅ Service Worker доступен по адресу `/sw.js`
- ✅ Manifest доступен по адресу `/manifest.json`

## 🎨 Кастомизация

### Изменить цвета приложения:

Отредактируйте `public/manifest.json`:

```json
{
  "theme_color": "#00ffff",  // Цвет темы (адресная строка на Android)
  "background_color": "#0a0118"  // Фон при запуске
}
```

### Изменить название приложения:

```json
{
  "name": "Intellect Pro School - Spelling Bee",  // Полное название
  "short_name": "Spelling Bee"  // Короткое название (под иконкой)
}
```

### Добавить шорткаты:

Уже настроены шорткаты для:
- 🎯 **Start Training** → `/training`
- 🏆 **Practice Mode** → `/practice`

## 🔧 Техническая информация

### Service Worker стратегия кэширования:

- **Network First** - Сначала пытается загрузить из сети
- **Cache Fallback** - Если сеть недоступна, использует кэш
- **Precaching** - Основные файлы кэшируются при установке

### Обновление приложения:

Service Worker автоматически проверяет обновления каждую минуту. При обновлении пользователь получит уведомление с предложением перезагрузить страницу.

## 🐛 Устранение неполадок

### Service Worker не регистрируется:

1. Проверьте консоль браузера на ошибки
2. Убедитесь что файл `public/sw.js` существует
3. Проверьте что приложение работает на HTTPS или localhost

### Иконки не отображаются:

1. Убедитесь что все иконки загружены в `public/`
2. Проверьте что имена файлов точно совпадают с манифестом
3. Очистите кэш браузера и перезагрузите страницу

### Приложение не предлагает установку:

1. Убедитесь что Service Worker работает
2. Проверьте что манифест корректен
3. На iOS используйте Safari (Chrome не поддерживает PWA install на iOS)
