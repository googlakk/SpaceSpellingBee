# Practice Features Documentation

## 1. Progress Persistence Feature

### Описание
Система автоматического сохранения прогресса ученика при тренировке слов. Прогресс сохраняется в localStorage браузера и восстанавливается при следующем посещении того же уровня.

## Что сохраняется

Для каждого уровня (sublevel) сохраняется:
- **currentWordIndex** - индекс текущего слова (на каком слове остановился ученик)
- **coins** - количество накопленных монет
- **streak** - текущая серия правильных ответов
- **hintsUsed** - количество использованных подсказок
- **lastUpdated** - время последнего обновления

## Как это работает

### Автоматическое сохранение
Прогресс автоматически сохраняется при каждом изменении:
- При переходе к следующему слову
- При использовании подсказки
- При получении/потере монет
- При изменении streak

### Автоматическая загрузка
При входе на уровень:
1. Система проверяет наличие сохраненного прогресса для данного sublevel
2. Если прогресс найден и индекс слова > 0, показывается уведомление: "Progress restored! Continuing from word X"
3. Восстанавливается состояние: позиция в списке слов, монеты, streak, количество подсказок

### Сброс прогресса
Прогресс автоматически сбрасывается:
- При успешном завершении всех слов уровня (Mission Complete)

Прогресс можно сбросить вручную:
- Кнопка с иконкой ракеты в панели Quick Actions
- При нажатии появляется уведомление и тренировка начинается сначала

## Технические детали

### Ключи localStorage
Прогресс хранится с ключом в формате: `practice_progress_${sublevelId}`

Пример: `practice_progress_abc123`

### API
Файл `src/features/track-progress/model/progressStorage.ts` предоставляет утилиты:

```typescript
// Сохранить прогресс
saveProgress(sublevelId: string, progress: PracticeProgress): void

// Загрузить прогресс
loadProgress(sublevelId: string): PracticeProgress | null

// Очистить прогресс уровня
clearProgress(sublevelId: string): void

// Получить все ключи прогресса
getAllProgressKeys(): string[]

// Очистить весь прогресс
clearAllProgress(): void
```

## Преимущества
1. ✅ Ученик может прервать тренировку и продолжить позже с того же места
2. ✅ Не теряется прогресс при случайном закрытии вкладки/браузера
3. ✅ Каждый уровень имеет независимый прогресс
4. ✅ Простой сброс прогресса для повторного прохождения
5. ✅ Автоматическая очистка при завершении уровня

## Ограничения
- Прогресс хранится только в браузере (localStorage)
- При очистке данных браузера прогресс будет потерян
- Прогресс не синхронизируется между устройствами
- Для каждого сублевела создается отдельная запись в localStorage

## 2. Words List Feature

### Описание
Интерактивный список всех слов в миссии с возможностью прослушивания аудио и перехода к любому слову.

### Функции

#### Просмотр списка слов
- Кнопка "All Words (N)" в панели Quick Actions
- Показывает все слова текущей миссии
- Визуальная индикация:
  - ✅ Зеленая рамка - пройденные слова
  - 🚀 Синяя рамка с подсветкой - текущее слово
  - Серая рамка - непройденные слова

#### Прослушивание аудио
- Кнопка с иконкой 🔊 рядом с каждым словом
- При нажатии воспроизводится аудио слова
- Работает для всех слов в списке
- Не влияет на текущий прогресс

#### Переход к слову
- Клик на само слово переносит к этому слову в тренировке
- Автоматически:
  - Закрывает модальное окно
  - Сбрасывает текущий ввод
  - Обновляет прогресс-бар
  - Показывает уведомление "Jumping to word N"
- Недоступно во время показа обратной связи (correct/incorrect)

### Технические детали
Файл: `src/pages/practice/ui/PracticePage.tsx`

Функции:
- `handleWordClick(index: number)` - переход к выбранному слову
- Аудио воспроизводится через нативный HTML5 Audio API

## 3. Mission Completion Feature

### Описание
Модальное окно с поздравлениями при успешном завершении всех слов миссии.

### Что показывается

#### Поздравительное сообщение
- 🎉 Эмодзи с анимацией
- "Congratulations, Space Cadet!"
- Количество пройденных слов

#### Статистика миссии
- **Total Words** - общее количество слов
- **Coins Earned** - заработанные монеты
- **Best Streak** - лучшая серия правильных ответов
- **Hints Used** - использованные подсказки

#### Кнопки действий

**Restart Mission** (основная кнопка)
- Сбрасывает прогресс миссии
- Начинает тренировку с первого слова
- Сохраняет выбранный уровень
- Показывает уведомление "Mission restarted from the beginning!"

**Return to Levels** (второстепенная кнопка)
- Возвращает к выбору уровней
- Переход на страницу `/training`
- Позволяет выбрать новую миссию

### Когда появляется
Модальное окно автоматически открывается при:
1. Правильном ответе на последнее слово миссии
2. Запуске confetti-анимации
3. Автоматической очистке прогресса

### Технические детали
Файл: `src/pages/practice/ui/PracticePage.tsx`

Состояние: `showCompletionModal` (boolean)

Функции:
- `handleRestartMission()` - перезапуск миссии
- `handleReturnToLevels()` - возврат к уровням

Компонент использует:
- Dialog из `@/components/ui/dialog`
- Иконки: Trophy, Star, Sparkles, Flame, Lightbulb, Rocket, Home
- Анимации: `animate-bounce-subtle`, `animate-shimmer`

## Интеграция функций

Все три функции работают вместе:
1. **Progress Persistence** сохраняет текущее положение
2. **Words List** позволяет переходить между словами
3. **Completion Modal** появляется при завершении и позволяет перезапустить

### Пример использования
1. Ученик проходит 5 из 10 слов
2. Закрывает браузер → прогресс сохранен
3. Возвращается → продолжает с 6-го слова
4. Открывает Words List → видит пройденные слова (зеленые)
5. Кликает на 3-е слово → возвращается к нему
6. Заканчивает все слова → видит Completion Modal
7. Нажимает "Restart" → начинает сначала
8. Или нажимает "Return to Levels" → выбирает новую миссию
