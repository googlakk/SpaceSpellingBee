# 📲 Кнопка "Установить приложение" - Краткое руководство

## 🎯 Что добавлено?

Теперь в приложении есть **удобная кнопка "Установить приложение"**, которая позволяет пользователям установить PWA в **один клик**!

---

## 📍 Где находится кнопка?

### 1. **На главной странице (HomePage)**
- Большая заметная кнопка
- Расположена под кнопками "Launch Training" и "Practice Mode"
- С фиолетовым свечением (glow-purple)
- Видна всем посетителям главной страницы

### 2. **В шапке сайта (Header)**
- Компактная кнопка в верхнем меню
- Доступна на **всех страницах** приложения
- Скрыта на очень маленьких экранах (< 640px) для экономии места
- Всегда под рукой во время навигации

---

## 🚀 Как это работает?

### На Android (Chrome/Edge):

1. Пользователь нажимает кнопку **"Установить приложение"**
2. Браузер показывает **нативный диалог установки**
3. Пользователь нажимает "Установить"
4. ✅ Приложение установлено!

**Скриншот:**
```
┌─────────────────────────────┐
│  Установить приложение?     │
│                             │
│  Intellect Pro School       │
│  - Spelling Bee             │
│                             │
│  [Установить]  [Отмена]     │
└─────────────────────────────┘
```

### На iOS (Safari):

1. Пользователь нажимает кнопку **"Установить приложение"**
2. Открывается **красивый диалог с пошаговой инструкцией**:
   - Шаг 1: Нажмите кнопку "Поделиться" 📤
   - Шаг 2: Прокрутите вниз
   - Шаг 3: Выберите "На экран «Домой»"
3. Пользователь следует инструкциям
4. ✅ Приложение установлено!

**Диалог выглядит так:**
```
┌────────────────────────────────┐
│ 📱 Установка на iOS            │
│                                │
│ ┌──────────────────────────┐  │
│ │ 1️⃣ Нажмите кнопку         │  │
│ │    "Поделиться" 📤        │  │
│ └──────────────────────────┘  │
│                                │
│ ┌──────────────────────────┐  │
│ │ 2️⃣ Прокрутите вниз        │  │
│ └──────────────────────────┘  │
│                                │
│ ┌──────────────────────────┐  │
│ │ 3️⃣ Выберите "На экран     │  │
│ │    «Домой»"              │  │
│ └──────────────────────────┘  │
│                                │
│      [Понятно!]                │
└────────────────────────────────┘
```

## 🎨 Умное поведение кнопки

Кнопка **автоматически скрывается**, когда:

✅ Приложение уже установлено как PWA
✅ Браузер не поддерживает PWA
✅ Пользователь уже установил приложение

Кнопка **показывается**, когда:

📱 Приложение открыто в обычном браузере
📱 PWA еще не установлено
📱 Браузер поддерживает установку

## 🛠️ Технические детали

### Компонент: `InstallButton.tsx`

```tsx
// Использование на странице:
import { InstallButton } from "@/components/InstallButton";

// Простое использование:
<InstallButton />

// С кастомными стилями:
<InstallButton
  variant="outline"
  size="lg"
  className="my-custom-classes"
/>
```

### Параметры:

- **`variant`** - стиль кнопки: `'default' | 'outline' | 'ghost'`
- **`size`** - размер: `'default' | 'sm' | 'lg'`
- **`className`** - дополнительные CSS классы
- **`fullWidth`** - растянуть на всю ширину: `boolean`

### Функционал:

- ✅ Автоматическое определение платформы (iOS/Android)
- ✅ Показ нативного диалога на Android
- ✅ Показ инструкций на iOS
- ✅ Автоскрытие после установки
- ✅ Отслеживание события `beforeinstallprompt`
- ✅ Адаптивный дизайн
